# Security Policy

## Reporting a Vulnerability

Everlog takes security seriously. If you discover a potential security issue, please **do not create a public issue**. Instead, report it privately to the maintainers:

- Email: [support@radobley.sk]

Include as much detail as possible (steps to reproduce, screenshots, device info, etc.) to help me assess and fix the issue quickly.

## Scope

This project stores user-generated data locally and in iCloud/CloudKit. Sensitive data like device serial numbers may be stored at the user’s discretion. Always follow best practices when handling personal or sensitive information.

## Response

I will review all reports promptly, and aim to acknowledge within 48 hours. If a fix is needed, I will release updates in a timely manner and notify affected users as appropriate.
